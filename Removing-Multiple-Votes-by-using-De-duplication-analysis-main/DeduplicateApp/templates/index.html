Project Overview: In democratic processes, electoral rolls often suffer from duplicate records due to clerical errors, multiple registrations across constituencies, or variations in voter names and guardian credentials. This system provides automated de-duplication through multi-attribute matching (Voter ID, Aadhar Number, and demographic clusters), generates cleaned Excel registries, and plots visual verification graphs.
